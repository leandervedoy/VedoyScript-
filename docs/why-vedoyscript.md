# Why a different syntax?

VedoyScript prioritizes explicit, readable instructions for common tasks. It may reduce boilerplate for simple web pages and make source approachable to newcomers.

Shorter source code is not automatically faster, smaller or more secure. We intend to measure full-project effort, emitted bytes, runtime latency and correctness before publishing comparative claims.

Strongest current applications: landing pages, small prototypes and educational examples.
