# Meet VedoyScript

**Less syntax. More creation.**

VedoyScript (`.vds`) is an experimental, readable language. Instructions begin with a capital letter, end with a period and use four spaces for nesting. The current beta creates simple web pages, content layouts, compile-time data and click interactions.

VedoyScript is **not yet** a substitute for JavaScript or TypeScript for arbitrary production applications. [View capabilities](./capabilities.md) and the [roadmap](./roadmap.md).
