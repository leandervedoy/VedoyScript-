# Roadmap

1. Establish a language conformance suite and publish the exact grammar.
2. Add expressions, control flow, functions, modules, errors and useful types.
3. Introduce typed data, promises/async and DOM/browser interfaces.
4. Support backends, HTTP, SQL and authentication through secure runtime APIs.
5. Move canonical compilation/build tooling to VedoyPolyglot without duplicating code.
6. Add optional JS/TS interop and native/WASM targets based on demand.
7. Benchmark source reduction, generated bytes and runtime speed against matched tasks.

Features graduate from *planned* to *beta* only with passing tests.
