# Layouts

Use `Section.`, `Row.` and `Column.` to group supported elements. Indent children with four spaces per level.

```text
Page "Portfolio".
    Heading "Projects".
    Row.
        Section.
            Subheading "One".
            Text "First project".
        Section.
            Subheading "Two".
            Text "Second project".
```

Styling is currently generated by the beta compiler. Full CSS-in-language and visual themes are planned.
